2.1:医保检查前的准备
1.医疗机构执业许可证正、副本
2.医、技人员资格证、执业证
3.医保科各项管理制度、医保的内部组织构架
4.医保培训记录（一年至少两次），医保日常监管记录（文字或者
图片材料）
5.康复治疗类、生化检验类等医疗器械三证，包括心电图机、彩超
机等
6.如果生化检验是外送第三方实验室，准备好第三方签定的协议、
送检目录等
7.放射设备需放射诊疗许可证、医疗器械三证、定期的检测报告等
8.核查时间段的职工考勤表，医师、技师为主
9.核算中医类、康复类的治疗时长与技师的工作时长是否匹配，中
医项目的细节描述（比如一个技师正常工作时长的多久，中医定向
透药透的是什么药？中药涂擦治疗擦的是什么药？并且药膏需要有
相应购买记录或者库存记录）
10.中草药为第三方代配的合同协议
11.西药、中成药、医疗耗材和普通耗材的进销存对比总结算量是
否匹配（期初库存+进货量-期末库存＞结算量）
12.氧气的进销存（氧气吸入项目开具的总量与氧气进销存是否匹
配）
13.检验科试剂三证以及采购试剂的进销存与开单量是否匹配
14.抽查病历的费用清单提前打印准备好，病历中需检查各种护理
记录单，如氧气吸入记录单、血糖监测记录单等是否齐全（缺失
等同于未做），化验单（重点需关注各种非常规开具化验单如微
量元素、药敏、血尿培养单是否缺失）、彩超单、放射单是否齐
全。
15.会诊记录单、治疗单需与医嘱收费匹配齐全，缺失等于没做，
当虚开项目处理，中医会诊记录、康复会诊记录需在病程录当中
记载。
16.中医、康复治疗单杜绝千篇一律时间开始，且治疗时长足够，
需要消耗时长的必须记录足够时长（如中医杵针+中医定向透药
治疗+内妇科推拿，其中两项目时长不可重叠，总耗时应在30分
钟以上）
17.重症及高热患者不可继续做康复治疗，康复时间较长的患者应
有阶段小结疗效评估，不可长时间无指征无疗效无会诊持续治疗。
18.限制性药物如亚胺培南、美罗培南（限多重耐药的重症感染）、
头孢替安、头孢哌酮钠舒巴坦钠、哌拉西林钠他唑巴坦钠（限有
明确药敏试验证据或重症感染的患者）等需重症感染多重耐药，
且药敏试验证据才可使用（经验性用药不可）
19.留置针只能收取费用静脉输液，不可收取动静脉置管护理费用，
动静脉置管护理为CVC、PICC、PORT等中心静脉导管的收费
20.患者长期测血糖，换药等需有分析有总结

2、血清间接胆红素：根据临床诊疗常规，血清间接胆红素由血清总胆红
素与血清直接胆红素数值相减得出，不应再收取费用。（调整收费规则）
3、血清a-L-岩藻糖苷酶测定（肝功能16项）：根据临床诊疗常规，该项用
于原发性肝癌的辅助诊断、疗效评价和复发诊断,（符合指征才能做，不
能直接开套餐）
4、降钙素原检测(化学发光法)：根据临床诊疗常规:降钙素原（PCT）是一
种蛋白质，当严重细菌、真菌、寄生虫感染以及脓毒症和多脏器功能衰竭
时，它在血浆中的水平升高；自身免疫、过敏和病毒感染时，PCT不会升
高或轻微升高；局部有限的细菌感染、轻微的感染和慢性炎症不会导致其
升高。细菌内毒素在诱导过程中担任了至关重要的作用。PCT只是在少数
患者的大型外科术后1-4d可以测到。C反应蛋白+降钙素原检测同时检测
（结果正常还重复检查多次）

检查要点
合理住院
•
无住院指征，应当在门诊检查治疗的患者收入院。
•
经过治疗后病情稳定、好转、痊愈可以出院的仍滞留住院。
合理用药
•
超范围用药：违反医保药品目录，将目录外药品纳入结算。
•
超限定用药：违反有关规定，超医保限定、超适应症、超科别等使用限制范围的药品。
•
无依据用药：开具与本次住院期间诊断、治疗、检查结果无关的药品或超说明书使用。
•
出院带药：超量、超品种或与出院诊断无关药品。（5个品种、2周）。
•
抗生素使用：频繁更换抗生素，未说明理由；长期使用同一类抗菌素；药敏试验明确有敏感药品却仍使用耐药抗生素；是否执行抗生素三级管理制度，特殊抗生素是
否有申请书，药事委员会签名。
•
违反配伍禁忌，不合理搭配使用药物。
•
违法医政、药政管理规定，滥用毒、麻、精神类药品。
合理检查（化验）
•
无指征检查（化验）：与本次疾病诊断、鉴别诊断、治疗原则的制定及疗效无关的检查（化验）。
•
指征过宽：不根据病情，用某些相对复杂、价格昂贵的特殊检查代替相对简单、价廉的检查（化验）。用全套代替单项检查，把特殊检查、专病检查列入常规检查。
•
重复检查化验：重复临床意义相同的同类检查或短期内无临床意义的重复同一种检查。
合理治疗
•
无指征治疗：不从病情出发，实施与病情无关或无实际治疗效果或无疗效观察和评价的治疗项目，也包括无治疗过程、病情变化及治疗效果记录的治疗。
•
过度治疗：指不从病情出发，不考虑病情需要和治疗效果，擅自扩大治疗范围，延长治疗时间，增加治疗项目或进行不合理联合治疗。
合理收费
•
违反医保规定：将基本医疗保险不予支付的费用（诊疗项目、药品、服务）纳入医保结算。
•
巧立名目收费：将未纳入医保报销范围的治疗、卫生材料等纳入医保结算。
•
无标准收费：将未经许可、批文过期、已删除项目擅自收费。
•
违反收费标准：自行抬价或不按规定及时间所以参照、套用收费，不执行限制收费标准。
•
分解收费：将应一次收费的项目分解成若干项目收费。
•
重复收费：将已收费总项目中某些单项再另行收费。
•
无依据收费：未提供服务或不能提供已服务依据而收费。
•
不按服务量收费：收费数量与病史等资料记录不符。
其他
