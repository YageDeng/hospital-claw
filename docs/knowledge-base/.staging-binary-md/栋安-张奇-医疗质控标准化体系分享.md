护士层级考核办法
护理部
1、1考核成绩组成：
①
病区考核平均分（百分制）*30%；
②护理的理论知识+基础操作+专科操作，三个成绩取平均分（百分制）*30%；
③护士沟通能力考评分数（百分制）*40%；
④以上三项分数相加为每个人本次考核成绩（取四舍五入）；
⑤加分项：参加业务学习培训：在考核成绩总分上+2分/次；
2、占比计算：N0占15%，N1占35%，N2占35%，N3占15%，总成绩采用四舍五入；
3、定级薪资计算按季度核算，中途不调整；
4、新入职护士满三个月即可申请层级考核，考核成绩参考上一季度各层级分
数线，确立等级；
5、连续两季度考核为N0者予以劝退。
