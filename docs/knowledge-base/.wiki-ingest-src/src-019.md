协爱集团信息化建设的情况介绍（文字稿）

信息化中心最难的是实现建设的标准化，包括架构、流程、预警值、控制值、管理值、工作量的基础标准、统一的物资价格、统一的代码口径等等。通过顶层设计，我们运用数字化解决了人、财、物、事这四大板块的管理体系。我们的管理者通过研究数字的应用，不断提出新的需求模块；我们的员工经过培训都能使用数据，我们实现了作业数字化、数字平台化、平台智能化、智能实战化的连锁发展。

人（人力资源信息化管理）

人才是企业发展最宝贵的财富。而人的管理又是最复杂的，也是最难解决的。

我们协爱从零到目前拥有万人团队，这么庞大的队伍如何管理？我们主要面临着四大考验：

1、我们人员的管理模式有集团直管、有集团和机构双管、也有机构院长自管，再加上各部门之间的协同，怎样才能既实现集团统一有效管理，又保证机构院长的自主权，最终实现战略闭环管理，执行流程不脱节？

2、我们的下属机构分布在不同的地区，又分别处于筹建期、初创期、发展期、成熟期和迭代期，各个地区各个阶段都需要不同的人才，而如此复杂的人才队伍该如何管理？

3、在我们集团中，人员文化层次落差非常大，有国医大师、博导，也有普通医技护和行政人员，还有文化水平不高连名字都写不清楚的护工、保安、保洁等，如此大的层级落差，怎样用一套管控体系和培育体系来实现人员管理？

4、我国劳动法保护的是劳动者的利益，而劳动者中难免也有个别人价值观不正，我们该如何控制“劣币行为”？

如何有效解决以上这些问题，协爱一直“把人才当作投资而不是成本”，认为培养出好的人才就是企业最大的利润。我们不但注重打造管理制度和企业文化；还花了大量的精力搭建数字化平台，助力人才管理和培养。具体有：

第一、员工在职全周期的数字化管理。

从接触新员工开始，通过系统自动收集相关信息，建立人才画像、入职材料等基础档案，定期对其进行多方面能力评估，并根据每个人不同的短板安排培训内容，实现员工信息的全流程跟踪。同时在系统上进行劳动合同管理，将有问题的离职员工纳入黑名单，以防集团下属其他机构再次录用；对于离职的优秀员工做好标注，如果该员工愿意再次加入我们，我们也乐于接纳。

第二、岗位胜任力的评估和离职率、淘汰率的控制管理。

岗位胜任力评估主要包括价值观、个人能力、岗位技能这三个维度，通过信息化将员工胜任力分成“优、良、差”三个等次，作为我们集团人才管理的工具。

对于“优”等次员工，我们在升职、加薪、绩效奖励方面就要考虑给他相匹配的待遇。如果“优”等次员工离职率达到最高预警值，就会触发系统预警，我们就要分析为什么留不住人才；如果发现“优”等次员工被淘汰了，说明管理者有问题，那么我们就要反过来对管理者进行审核。

对于被评“差”的员工，就要分析评“差”的原因：1、评价为差的依据是不是足够充分？2、有没有对他进行再培训或者调岗？3、如果真是“差”等，为什么没有被淘汰？同样，“差”等级的员工的淘汰率、离职率如果低于预警值，系统也会触发预警；而连续3个月都评为“差”的员工仍没有被淘汰，也会触发预警。

第三、关于岗位、培训、薪酬的管理。

我们对不同部门、不同机构设置不同的架构、岗位、编制和薪酬，系统都会设置标准的管控数据，一旦超过管理值，就会触发系统预警，会根据设定的管理权限进行干预。

我们在系统上开发了员工培训模块，每一个新员工都可以借此全面了解自己的岗位要求和岗位职责。培训的内容包括：岗位说明书、管理手册、操作手册、管理制度等等。

我们的绩效方案，是根据不同的机构、不同的时期、不同的岗位、不同的技能、不同的阶段目标而制定的，这样多维度的绩效考核能有效激发员工的积极性。

财（财务信息化管理）

随着医保支付改革持续深化，DRG/DIP支付推行，要求医院更加精准核算每个病种的成本，确保医保资金合理使用；同时医院对于成本精细化控制也越来越高，要从设备采购、药品耗材支出、人力成本核算等等严格把关。我们通过借助人工智能、云计算和大数据等技术实现流程审批自动化、业务数据共享，实现业务和财务一体化（业财融合）。下面列举几个财务信息化运用的场景。

关于设备采购：我们对每一台设备要有评估数据。新采购的医疗设备，预设的系统会自动记录这台设备每次使用情况，从而自动分析设备的使用率、收益率和闲置率，为我们再次采购此类设备提供评估依据。如果出现闲置率高的情况，系统在收到采购此类设备指令时，会自动推送闲置信息，便于我们在机构之间进行调配。

关于绩效核算：前面讲到，我们的绩效方案是多维度，如果是人工计算就非常繁琐。我们的信息化系统已经提前录入了每个员工的绩效方案模版，会根据HIS系统数据、各个考核维度完成情况等，自动取数核算出每位员工的绩效。既提供了准确性，又有效核算出每位员工的人力成本。

关于财务核算：我们协爱是连锁集团，30多家医疗机构、为确保账目清晰、准确、及时性，我们打通了业务及财务端口；his系统每天自动推送收费结账信息到财务系统形成相关财务凭证；his系统的存货模块也会每天自动推送物资入库信息到财务系统形成相关财务凭证，形成准确进销存以及应付账款信息；费控系统从报销到银企直连支付再到财务凭证生成也形成了支付闭环；即增加了财务核算准确性，也减少了财务人员人工搬运数据的工作量。

关于财务分析：集团从his系统直接抓取科室收入、科室人员配置、以及相关成本数据，以及从财务系统抓取相关费用数据，自动生成与预算编制口径一致的分析报表，进行自动化数据分析，使分析跳出单一财务数据，辐射到相关业务数据，究其形成动因，从而更有深度的进行财务分析。

物（物资信息化管理）

医疗机构的物资种类要比一般的企业更为繁多，仅医疗类物资就有上万种，非医疗类物资也多达数千种。

医疗物资的管理是极为严格的，一根针，一粒药都不能出现丝毫的差错，在采购、使用等进销存各环节都必须保证库存合理、高效运转，所以，对所有物资进行信息化管理尤为重要。我们用数字化、智能化实现了全集团物资管理的集中化和一体化。

第一，关于物资采购的管理。

1、我们对采购过的每一项物资建立了相应标准化的参数标准，如：品牌、规格、型号、价格的参数信息。系统会根据授权进行比价，价格低于设定标准的可以直接进行采购；价格高于标准的，系统会触发审批程序。机构的库管必须按采购参数标准进行验收入库。

2、我们会根据系统的反馈筛选出优质供应商，同时也会将不合格的供应商列入黑名单。

3、我们根据不同机构的发展、实际使用情况分别设定库存最高值和最低值，采购系统会实时更新库存信息。当系统提示库存达到最低值时，我们就按库存最高值下单。

4、入库的每个物资都有代码，从一级库到二级库，整个出入库和使用过程都有迹可循。当发现临期、滞销的物品时，系统就会自动提醒并发出处置指令。

第二，关于固定资产的管理。

我们对每一件固定资产都分配一个编码。这样在使用时，只要一扫码，系统就会自动跳出该设备的有关信息，方便新医生快速了解这台设备的功能、适应症、说明书等。这样管理者也能随时掌握该设备目前所处机构、所处科室。

事（运营信息化管理）

医疗机构运营极其繁琐，难度要远高于酒店，而民营医疗机构运营难度更高，要有好的口碑、好的服务、好的管理。我们协爱一直致力于借助人工智能手段建立一套标准化、模块化、数字化、可复制的运营管理系统。

1、用标准生成经营数据。针对门诊，我们在管理系统上设置了收入结构、单体患者费用、复诊率及转住院率、专家信息等数据标准。而住院更为复杂，我们除了设置床日均费用、科室收入、患者来源、患者出院原因等大模块标准之外，还设置了药品费占比、检查检验费占比、高压氧舱占比、中医占比、康复占比、治疗占比、药品使用率、次均费用等小模块标准。通过这些数据标准的设置，为我们的经营决策提供数据支撑。

2、用数据判断经营策略。我们的管理系统根据提前设置的数据模块和相应标准，会主动抓取当日、当月乃至全年整个医院或者门诊部的运营数据，大到整个机构的医疗费用总和、小到单个患者单次的医疗费用，然后自动生成各类经营数据分析的曲线图、饼状图、柱状图、对照表等，让我们集团决策者和机构负责人清晰掌握整个医疗机构的经营状态。通过数据对比分析，一方面集团可以决策是否需要干预该医疗机构的运营，另一方面机构负责人可以根据经营各项数据作出经营策略、管理措施的调整。

3、用预警值管控经营。从庞大的经营数据中制定出管控标准值，提前在系统中设置管控预警值区间，也就是说当每一项的经营数据出现异常，高于或者低于预警值区间，都会触发预警提醒，由系统根据管理权限将异常推送给相应权限管理者进行介入。比如，某位医生的医疗行为明确不符合系统设置要求，但他还是强制执行了，那么就会触发系统预警，这样相应管理者就要介入，判断该医疗行为是否合规，从而杜绝不合理或不合规医疗行为的发生，确保我们协爱医疗机构合法合规运营。

4、用Deepseek等AI软件规范病历、处方。在住院临床中，医生书写病历错误的情况并不少见，运用Deepseek、豆包等AI软件形成标准化的病历模版，一方面可以避免病历错误、节省医生时间；另一方面确保医保DRG/DIP推行中更有效将病人智能化匹配入组，避免不熟悉医保政策造成入组错误的损失。在门诊开处方时，信息化系统也能通过病历录入，AI会判断用药是否禁忌匹配，自动开出合适的处方供医生来选择，这样更能保证医生处方的合理性和科学性。
