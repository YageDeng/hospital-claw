# 医保监督检查沟通会



**Source:** `医保监督检查沟通会.docx`



医保监督检查沟通会2025.7.25

参会人员：医保局长，医保任科长，2位专家组，门诊部人员，夏萍，王萌，明明，黄金金，秦姗姗，齐智同

会议内容：

外治法处方，要用松江的治疗单，不能按照1-8的数据写，要写具体项目，部分外治法治疗单，1个医生给相同的患者在做治疗非常不合理

中药处方中砂仁是先煎，后下的，系统中要及时整改

红参只能用于急救用使用医保，门诊不能使用，需把他改为自费项目

白芍，炒酸枣仁，远志，川贝母，超量，要双签，同时，医务科需要备案，

外治法治疗单，一天只能做一次，不能做2次

芒针不能随便用，只有部分的穴位可以使用，外治法开单做治疗，只能按照一周3次，一周4次的来做，不能按照1周5次，一周7次的来做，不可以，不能超开，属于过度诊疗

药物罐使用的中药粉，不能按照个人的名义来从门诊部购买，需要按照门诊的耗材使用来管理。

有好的初心，医疗机构提供诊疗服务，不是把盈利放第一位，所有的都在合法合规的基础上来做。

我们要有敬畏之心，医保基金的管理，医保基金管理条例，相对应的法律法规，底线不能碰。

要有责任心，对自己的行为负责，对法定代表人负责。
