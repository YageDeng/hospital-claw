# 处方审核清单

## 一、处方完整性检查

### 1.1 必须具备的信息（缺一不可）

| 序号 | 检查项 | 说明 | 缺失处理 |
|------|--------|------|----------|
| 1 | 患者信息 | 姓名、年龄/性别 | 提醒补充，年龄影响剂量判断 |
| 2 | 临床诊断 | 西医/中医诊断 | **必须**，无诊断无法审核诊断-处方匹配 |
| 3 | 中医证型 | 如"气滞血瘀证" | **必须**，证型决定方剂选择合理性 |
| 4 | 处方组成 | 药名+每味药剂量 | **必须**，核心审核对象 |
| 5 | 剂量单位 | g/ml等 | 缺失则无法判断超量 |
| 6 | 用法 | 煎服/冲服/外用等 | 影响剂量合理性判断 |
| 7 | 用量 | 每日次数/每次量 | 影响总剂量判断 |
| 8 | 帖数 | 几帖 | 影响总用药量判断 |
| 9 | 开方日期 | 处方时效性 | 超期处方提醒 |
| 10 | 医师签名/签章 | 处方合法性 | 缺失为不规范处方 |

### 1.2 加分项（有则更完整）

- 煎煮方法（先煎、后下、包煎等特殊标注）
- 注意事项/忌口
- 随诊要求
- 诊断与处方的关联说明

## 二、处方格式规范性检查

- [ ] 处方前记（患者信息）完整
- [ ] 处方正文（药品名称、剂量、用法）清晰
- [ ] 处方后记（医师签名、审核/调配/发药人签名）完整
- [ ] 中药饮片名称使用正名（非别名/俗名）
- [ ] 剂量单位规范（g，非钱、两等旧制）
- [ ] 特殊煎法标注（先煎、后下、包煎、烊化、冲服）

## 三、诊断-处方匹配检查

- [ ] 证型与方剂治法相符
- [ ] 主治与诊断对应
- [ ] 加减药味与证型变化吻合
- [ ] 无明显与诊断无关的药味

## 四、审核结论判定标准

| 结论 | 条件 |
|------|------|
| ✅ 通过 | 完整性合格 + 无配伍禁忌 + 无超量 + 医保合规 |
| ⚠️ 存在问题 | 有超量但可解释 / 有轻微配伍问题需确认 / 信息不完整但可补 |
| ❌ 不合规 | 存在十八反/十九畏 / 毒性饮片超量 / 医保限支付品种不满足条件 / 诊断缺失无法审核 |
