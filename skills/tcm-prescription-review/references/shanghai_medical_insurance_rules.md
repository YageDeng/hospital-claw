# 上海市中医类医保项目新政策（2025年7月25日实施）

> 信息更新时间：2025年7月22日（来源：李文海）

## 一、重要前提

### 实施时间节点
- **2025年7月25日零点**起执行新项目价格
- 7月24日晚上11点59分前仍按老项目结算
- 接受**医保局、卫生健康委**等多部门联合监管，违规将依法严肃查处

### 与历史项目的主要区别

**1. 计价单位全面改革**
- 原本按**穴位/罐**计费 → 改为**按次**，甚至**次/日**
- 原本按次收费 → 改为**按部位**
- 所有按次收费的项目，**默认一次治疗只能开一次**

**2. 新增"加收项"概念**
- 例：儿童加收、主任医师加收
- 理解为：同项目给儿童做，或主任医师来做，可额外加收
- 处理原则：没有明确价格的加收项 → 建议**不增设**
- 加收项不可和职称同时双重收取（取最高职称一项）

**3. 儿童年龄定义**
- 明确：**6周岁及以下**可按儿童加收
- 主任医师不可和副主任医师同时加收（取最高职称一项）
- 职称加收可和儿童加收**同时收取**

**4. 加收项 vs 拓展项区分**
| 类型 | 含义 | 示例 |
|------|------|------|
| 加收项 | 在基础服务上加了什么东西，所以加钱 | 中医拔罐 + 药物罐（加收） |
| 拓展项 | 基础服务的另一种做法，是单独一个选项 | 中医拔罐-火罐（拓展） |

**5. 加收金额计算规则**
- 按15%或20%计算后：
  - 小于等于1元 → **按1元收取**
  - 大于1元 → **抹零取整**（如7.5元 → 7元）
- 示例：50元项目加收15% = 7.5元 → 收7元（实付57元）

## 二、灸法类（统一按次收费，不再按穴位）

| 序号 | 项目名称 | 一级医院价格 | 注意事项 |
|------|---------|------------|---------|
| 1 | 悬空灸 | 21元/次 | 灸法类一次治疗**只能开一种** |
| 1.1 | 悬空灸-雷火灸（太医神针） | 21元/次 | |
| 2 | 直接灸 | 21元/次 | |
| 3 | 隔物灸 | 25元/次 | 间隔物包括：姜、蒜、附子饼、盐、中药粉等 |
| 4 | 铺灸 | 50元/次 | 脱脂棉片铺于胸腰腹后再施灸 |

**审核要点：**
- 四种灸法**一次治疗只能开其中一种**
- 同部位**不建议和TDP灯一起开**（皮肤过热会引发不必要罚款）

- 隔物灸：同一治疗用几种间隔物**不叠加收费**
- 铺灸-督灸（火龙灸）**暂未上线**，价格约100元

4. 同一部位**不建议做3种以上治疗**，建议写不同穴位
5. 手法松解术和推拿项目**同一部位不能同时开具**

## 九、专家补充规则

来自沁宇堂实际医保检查案例：

1. **多病种推拿规则**：开多个推拿 → **必须对应多个不同疾病**（不能用同一病名开多个推拿）
2. **骨伤科治疗适用性**：手法松解术属于骨伤科项目；**中医门诊无骨伤科 → 不应开具**
3. **同部位治疗数量限制**：同一部位 → **尽量不要做3种以上治疗**
4. **推拿部位名称准确性**：四肢推拿部位 = 上臂、前臂、**大腿**、小腿；**肩膀不属于四肢**

## 十一、审核优先级

1. **致命风险**：违反上述任一规则 → 必须拦截
2. **合规风险**：超量、不规范加收项 → 提醒确认
3. **规范性**：计价单位错误、项目名称不规范 → 建议修正
